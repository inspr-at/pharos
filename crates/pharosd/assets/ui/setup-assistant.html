    Verify this new server

    Use Hetzner's own web console so you are not trusting the same network path that SSH will use.

    1. Open Hetzner Cloud Console, open this server, then click Console / Konsole.
    2. Log in to the server console and run ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256.
    3. Copy only the part beginning with SHA256:. This fingerprint is public verification data. Never copy a private key.
